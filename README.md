# OKYUNSUN Idea Group Website

Production website source for https://www.okyunsunideagroup.com/

## Deployment
This repository is intended to be connected to the Vercel project `okyunsunideagroup`.
Production branch: `main`.
Every push to `main` should trigger an automatic production deployment on Vercel.

## Main files
- `index.html` — website
- `vercel.json` — Vercel configuration
- `robots.txt` / `sitemap.xml` — search engine files
- `favicon.png`, `logo.png`, `icon-192.png`, `icon-512.png`, `site.webmanifest` — brand/browser assets
